## 2025-05-15 - Improving CLI Interactivity with @clack/prompts
**Learning:** Using `@clack/prompts` over basic `node:readline` provides a much more polished and user-friendly experience for interactive CLIs, including better visual feedback, easier handling of cancellations, and consistency across different CLI commands within the same tool.
**Action:** Replace manual `readline` interfaces with `@clack/prompts` (intro, text, select, outro) to create a more cohesive and delightful terminal experience.
